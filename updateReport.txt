# SchoolERP — Update Report

Date: 2026-08-29

## Milestone 1: Project scaffold & foundation

Initialized the SchoolERP project (PHP 8 + MySQL / XAMPP) in the repository root.

### Added
- `.gitignore` — excludes vendor/, local config secrets, logs, editor files.
- `database/schema.sql` — full MySQL schema (`school_erp`) covering all 6 modules:
  - Staff Management (`staff`, `staff_documents`)
  - Auth (`users`, ties to staff)
  - Students + Classes/Sections (`students`, `student_enrolments`, `classes`, `sections`)
  - Finance (`fee_structures`, `fee_payments`, `payroll_periods`, `payroll_entries`, `staff_salary_basis`, `petty_ledger`)
  - Exam & Results (`exams`, `subjects`, `exam_schedules`, `exam_results`, `teacher_subjects`)
  - Timetable (`timetable_slots`, `timetable_entries`)
  - Notifications (`notification_logs`), settings table
  - Seed data: default academic session, admin user (admin/admin123), 6 timetable slots.
- `config/config.php` — app, DB (root/empty per spec), notification gateway config.
- `app/` core:
  - `App.php` (boot, config, paths, redirects)
  - `Database.php` (PDO-free mysqli wrapper: prepared statements)
  - `Auth.php` (login, session, role guards)
  - `helpers.php` (e, redirect, old, flash, csrf, formatting)
  - `view.php` (view + layout rendering)
  - `Router.php` (GET/POST router with {param} placeholders, CSRF + JSON support)
  - `routes.php` (route table + autoloader for controllers)
- `public/index.php` — front controller / router.
- `public/assets/css/app.css` — professional, responsive admin UI.
- `public/assets/js/app.js` — confirm dialogs, auto-dismiss alerts, check-all, auto-submit filters.
- Controllers: `AuthController`, `DashboardController`.
- Views: `layouts/app`, `auth/login`, `dashboard/index`, `errors/404`.

### Current status
- Purpose-built, modular single-root PHP app. Runs via `php -S 127.0.0.1:8000 -t public public/index.php` or Apache docroot → `public/`.
- NOT yet DB-connected at runtime (schema exists, DB install flow pending).
- Still to build: Staff, Students, Classes, Promotion, Finance, Exams, Timetable, Notifications controllers/views.

### Environment note
- XAMPP MySQL is running (port 3306) but `root` with empty password is currently rejected by the running server (the bundled `passwords.txt` says empty, but the live server denies it). Config targets root/empty per spec; final DB provisioning step will confirm/reset credentials.

## Milestone 3: Students + Classes & Sections + Bulk Promotion

### Added
- `app/controllers/StudentController.php` — registration + full CRUD:
  - List with search, session/class/section filters, pagination.
  - Registration form: personal, guardian, enrolment (session/class/section).
  - Profile with fee payment history + enrolment history.
- `app/controllers/ClassController.php` — class & section management:
  - Add class (with multi-section creation), add section (room, capacity, class teacher), delete.
  - Enrolment-based student counts.
- `app/controllers/PromotionController.php` — bulk promotion:
  - Select students, choose target session + option (next class / same class / graduate).
  - Creates new enrolment in target session, sets `promoted_from_class_id`, marks status
    `promoted` or `graduated` when no next class exists.
- Views: `students/index`, `students/form`, `students/show`, `classes/index`, `promotion/index`.
- Routes for promotion + section management.

### Guards
- Students: any logged-in user. Classes/sections/promotion: admin + accountant.

## Milestone 4: Finance module

### Added
- `app/controllers/FinanceController.php`:
  - **Overview** dashboard (fees collected, monthly fees, petty income/expense, payroll paid).
  - **Payroll**: list periods, generate a payroll period (auto-created entries from each staff
    member's salary basis: basic + allowances − deductions = net), mark a period as paid.
  - **Fee management**: fee structures per class (amount + frequency), collect a payment
    (auto receipt number, mode, reference), list all payments with search.
  - **Petty income/expense**: ledger with type filter, totals, and add-entry form.
- Views: `finance/_nav` (shared sub-nav), `overview`, `payroll`, `payroll_generate`, `fees`,
  `fee_payments`, `petty`.
- Routes for all finance actions.

### Guards
- Payroll, fee structure, fee collection, petty: admin + accountant. Viewing fee payments: any login.

## Milestone 5: Exams & Results module

### Added
- `app/controllers/ExamController.php`:
  - Exam management: create, list, view with enrolled students.
  - **Schedule**: add/remove subjects (date, time, full/pass marks) per exam.
  - **Results entry**: grid of students × subjects with marks + remarks; auto grade
    (A+/A/B/C/D/F based on full marks); empty cells delete the result row.
  - **Report card**: per-student summary with total, percentage, PASS/FAIL, printable
    (print CSS media rules).
  - **Subjects**: create subjects, assign teachers to subjects, remove assignments.
- Views: `exams/index`, `exams/create`, `exams/show`, `exams/schedule`, `exams/results`,
  `exams/report_card`, `exams/subjects`.

### Guards
- Create/schedule/results: admin + accountant + teacher. Create exam/subjects/schedule: admin + accountant.

## Milestone 6: Timetable module

  `timetable/slots`.

### Guards
